----------------------------

- pip package manager
- Virtual environment (recommended)
- 500MB disk space

STEP 2: PROJECT SETUP
---------------------
# Navigate to project directory
cd stegomail_logger

# Create virtual environment (RECOMMENDED)
python3 -m venv venv

# Activate virtual environment
# On Linux/Mac:
source venv/bin/activate
# On Windows:
venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Alternative: Install without virtual environment (not recommended)
pip3 install --break-system-packages -r requirements.txt

STEP 3: VERIFY INSTALLATION
---------------------------

================================================================================
                                BASIC USAGE
================================================================================

STEP 1: CREATE SAMPLE FILES
---------------------------
python3 main.py samples

# Creates:
# - sample_keylogger.py (basic payload)
# - enhanced_keylogger.py (advanced payload)  
# - sample_cover.png (cover image)

STEP 2: ENCODE PAYLOAD INTO IMAGE
---------------------------------
python3 main.py encode --payload sample_keylogger.py --image sample_cover.png --output stego_image.png

# This embeds the keylogger into the image using LSB steganography
# Creates: stego_image.png (contains hidden payload)

STEP 3: DECODE PAYLOAD FROM IMAGE
---------------------------------
python3 main.py decode --image stego_image.png --output extracted_payload.py

# This extracts and decrypts the hidden payload
# Creates: extracted_payload.py (should match original)

STEP 4: SIMULATE IMAGE OPENING (EDUCATIONAL)
--------------------------------------------
python3 main.py open --image stego_image.png --no-display --force

# Simulates opening image and executing payload
# --no-display: Don't show image
# --force: Override safety checks (educational use only)

================================================================================
                              TROUBLESHOOTING
================================================================================

COMMON ISSUES AND SOLUTIONS:

1. IMPORT ERRORS
---------------
Error: ModuleNotFoundError: No module named 'PIL'
Solution: pip install Pillow

Error: ModuleNotFoundError: No module named 'pynput'
Solution: pip install pynput

Error: ModuleNotFoundError: No module named 'cryptography'
Solution: pip install cryptography

2. PERMISSION ERRORS
-------------------
Error: Permission denied
Solution: 
- Use virtual environment
- Check file permissions: chmod +x main.py
- Use sudo if necessary (not recommended)

3. EMAIL AUTHENTICATION FAILS
-----------------------------
Error: SMTP authentication failed
Solution:
- Check credentials in config.json or .env
- Use App Password for Gmail (not regular password)
- Enable "Less secure app access" (not recommended)
- Verify SMTP server and port settings

4. PAYLOAD EXTRACTION FAILS
---------------------------
Error: No valid payload found
Solution:
- Verify image was encoded properly
- Check encryption settings match
- Ensure image file is not corrupted

5. ENVIRONMENT SAFETY BLOCKS EXECUTION
--------------------------------------
Error: Environment safety check failed
Solution:
- Use --force flag for educational override
- Run in VM or educational environment
- Check hostname contains educational indicators

6. KEYLOGGER NOT CAPTURING
--------------------------
Error: No keystrokes captured
Solution:
- Run with sudo on Linux (for device access)
- Check if running in GUI environment
- Verify pynput installation

ENCODE OPTIONS:
--------------
--payload PAYLOAD     Path to payload file (required)
--image IMAGE         Path to cover image (required)

DECODE OPTIONS:
--------------
--image IMAGE         Path to steganographic image (required)
--output OUTPUT       Path to save extracted payload (optional)
--quiet              Suppress payload preview

OPEN OPTIONS:
------------
--image IMAGE         Path to steganographic image (required)
--no-display         Don't display image
--no-execute          Don't execute payload
--force              Override safety checks
